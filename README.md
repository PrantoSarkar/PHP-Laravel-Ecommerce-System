# Online Shopping System with PHP Laravel

This repository contains an e-commerce web application developed using the PHP Laravel framework.

The project was created as an academic software development project and provides the core functionality of an online shopping platform.

## 📌 Project Information

**Project:** Online Shopping System

**Framework:** Laravel

**Language:** PHP

**Project Type:** Academic Project

**Completed:** December 2020

## 🛒 About the Project

The Online Shopping System is a web-based e-commerce application that allows users to browse products, add items to a shopping cart, and place orders.

The system also includes administrative functionality for managing products, users, and customer orders.

## ✨ Main Features

- User registration and login
- User authentication
- Product browsing
- Product catalog management
- Shopping cart
- Add/remove products from cart
- Order placement
- Order management
- Admin dashboard
- Product management
- User management
- E-commerce workflow

## 🛠️ Technologies Used

- PHP
- Laravel
- HTML
- CSS
- JavaScript
- MySQL
- Bootstrap

## 🎯 Project Objective

The main objective of this project was to understand and implement a complete web-based e-commerce system using Laravel.

Through this project, I gained practical experience in:

- MVC architecture
- Laravel routing
- Controllers and models
- Database integration
- User authentication
- CRUD operations
- Shopping cart implementation
- Order management
- Admin panel development
